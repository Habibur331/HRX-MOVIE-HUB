# HRX Movie Hub

A responsive movie discovery website starter built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the `hrx_movie_hub` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit the sample movie list in `script.js`.

## Included
- Responsive dark-themed homepage
- Search by title or genre
- Genre filters
- Movie details dialog
- Official-trailer search link
- Clear placeholder for authorized watch/download links
